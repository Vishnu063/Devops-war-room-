# NovaCart

India-first shopping application with a database-backed storefront, customer accounts, owner administration, inventory-safe checkout and operational workflows. **Development verified; not production-ready.** Fictional seed products and original SVG illustrations are explicitly demonstration content.

Run the Node service for integrated shopping; opening `index.html` directly cannot provide database or account workflows. The old `checkout-demo.html` remains an explicitly simulated standalone demo and is not the actual order checkout.
